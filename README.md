# 🐱 Наши хотелки

Милый вишлист для двоих. Открывается по ссылке, вход по логину и паролю,
хотелки сохраняются в GitHub и видны друг другу.

Сайт: **https://roman-ttrn.github.io/nashi-hotelski/**

## Как это работает

Это статичный сайт (HTML/CSS/JS), который GitHub Pages отдаёт как есть.
Данные (хотелки) лежат в отдельном приватном репозитории
[`nashi-hotelski-data`](https://github.com/roman-ttrn/nashi-hotelski-data)
и читаются/обновляются через GitHub API по ключу доступа.

Ключ доступа вводится один раз на устройстве и хранится только в браузере
(`localStorage`). В коде сайта никаких секретов нет.
